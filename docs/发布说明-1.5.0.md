# 晚安助手 1.5.0 · 计划状态与软件更新

Windows 10/11 x64 安装包，当前用户安装，无需额外安装 Python 或 Node.js。

- 新增手动检查更新：在“外观与通知 → 软件更新”或系统托盘操作。
- 默认启动 8 秒后自动检查，运行期间每 4 小时检查一次 GitHub 正式发布版，可关闭。发现新版提供下载入口，遵循桌面通知设置；不会自动下载、安装或打断签到。完全退出程序后停止检查。
- 分钟上下调整可跨小时，22:00 减一分钟为 21:59；新保存时间范围为北京时间 **21:30–23:30**，到边界停止。原有范围外配置会提示重新选择时间。
- 窗口外框与标题栏跟随主题，支持系统磨砂材质并保留原生窗口操作；不支持材质效果的系统自动降级。
- 主页增大启用状态和倒计时，使用清楚的对勾；直接显示任务缺失、停用、时间/执行路径不匹配和保存失败原因。
- 明确区分“系统任务结束”和“学校已确认签到成功”，没有成功记录时提示核实。
- 计划保存通过单次后台进程完成注册与回读校验，失败时尝试恢复原任务和配置。修复旧版任务接管的来源校验与状态恢复。
- 保留两个账号独立计划、在线验证、静音动态壁纸、主题、托盘及通知。升级保留账号和计划，发布内容不包含开发者个人数据。

下载附件 `AHUTSignIn-Setup-1.5.0-x64.exe`。更新前从托盘退出旧程序，等待签到执行完成，再安装新版。
