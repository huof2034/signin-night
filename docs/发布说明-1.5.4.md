# 晚安助手 1.5.4 · 程序内一键更新

- 发现新版后点击“现在更新”，在程序内下载、校验 SHA-256、原位安装并重启。
- 更新模式保留账号、系统计划的执行路径、时间和启用状态，不重建签到计划。
- 下载失败可重试；安装前备份程序文件，安装或自检失败时尝试恢复。程序文件被签到进程占用时取消本次更新，不终止签到。

从 1.5.3 或更早版本首次升级，请运行附件 `AHUTSignIn-Setup-1.5.4-x64.exe`。之后可以使用“现在更新”。安装包未签名，SHA256SUMS.txt 提供完整性校验。

验证：160 项离线回归测试通过（包含实际进程互斥测试）。在独立目录验证原位升级、自检、重启和版本校验失败后的旧程序恢复；现有系统签到任务 XML 前后保持一致。测试不提交真实学校签到。
