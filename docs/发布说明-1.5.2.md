# 晚安助手 1.5.2 · 本地签到记录修复

- 学校返回明确成功响应时，立即写入当前账号的独立成功回执并回读校验，不再等待后续随机延时和会话清理结束才保存。
- 界面同时检查独立回执和兼容成功文件。旧文件损坏、写入失败或后续清理异常，不再丢失已经保存的成功结果；最近执行也会显示回执信息。
- 学校已确认成功但本地回执保存失败时，单独提示“回执保存失败”，避免误报为学校拒绝签到；已有成功确认时阻止重复提交。
- 主页增加“从成功日志修复本地记录”。严格核对账号归属、执行时间、成功日志和任务信息；证据不足时不修改记录。恢复后注明日志来源，保留原记录备份，**不重新提交签到，也不冒充本次联网核验**。
- 暂停、未接管、超出执行窗口等跳过情况会记录具体原因，避免将系统退出码 0 等同于签到成功。
- 运行事件通过跨进程锁写入，并同步到磁盘，减少界面与定时进程同时写记录时丢失事件的风险。

下载附件 `AHUTSignIn-Setup-1.5.2-x64.exe`。升级前从托盘退出旧程序，并等待正在执行的签到完成；账号、主题及计划保留。安装包不含开发者账号、回执、恢复备份、日志、密钥或个人壁纸。
