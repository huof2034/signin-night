# 晚安助手 1.5.0 中文使用说明

## 安装

运行发布页的 x64 安装程序，选择当前用户可写的目录。默认路径为 `%LOCALAPPDATA%\Programs\AHUTSignIn`。安装程序创建桌面和开始菜单快捷方式，在 Windows“已安装的应用”中提供卸载入口。

Windows 10/11 x64 是目标平台。无需安装 Python、Node.js 或 Wallpaper Engine 即可使用考勤功能；只有动态壁纸主题需要本机已有 Wallpaper Engine 和兼容壁纸项目。安装包没有代码签名，请从本仓库发布页下载并核对 SHA256。

## 添加与切换账号

输入学校学号及考勤密码，点击“验证并进入”。考勤系统默认密码为：`Ahgydx@920`；程序不会自动填入。改过密码的账号请使用修改后的密码。

首次添加必须在线验证。密码错误、接口不可用或网络断开会提示失败，留在登录界面，可以修改后重试；不保存未验证的新账号，也不提交签到。已有账号可离线进入管理界面，离线进入本身不会重新验证密码。

普通版最多保存两个账号，在侧栏选择当前账号。“添加账号”保存第二个账号；“移除账号”需确认，会暂停对应任务、删除其本机凭据及成功记录，不影响另一个账号。凭据损坏时可移除后重新添加。

## 设置自动签到

每个账号分别选择每日北京时间并启用。默认 22:00，新添加账号默认暂停。时间范围为 21:30–23:30，学校允许时段以实际考勤系统为准。切换账号不改变其他账号的计划。

电脑必须开机、当前用户已登录、联网且能访问学校系统。锁屏无需保持窗口打开。不要依赖关机、退出登录或断网后的自动执行。系统支持时定时任务会请求唤醒睡眠电脑；需由用户电源策略允许。任务仅在设定时间后的 15 分钟窗口内接受执行，单次执行中有限重试（总超时 180 秒）。失败不会自动全天循环重试，成功后通过账号与日期记录防止重复提交。

通过 Windows“任务计划程序”可查看 `AHUT-WQQD-Desktop-Daily` 和 `AHUT-WQQD-Desktop-Daily-Secondary`，第二个任务在对应计划保存后出现。不要直接修改任务；请在应用内暂停或修改时间，保持界面与系统设置一致。

## 托盘、通知和主题

关闭窗口收起到托盘。双击托盘或使用菜单恢复窗口；“退出”完全结束界面。托盘运行时通知结果，界面退出后计划仍由 Windows 运行，不弹出界面通知。日志页按账号显示事件，是否成功以学校接口确认及成功记录为准。

浅色、夜间、跟随系统、壁纸适配可随时切换。壁纸模式默认读取 Wallpaper Engine 当前项目，并在兼容时静音独立播放同一项目，不保证动画逐帧同步。它不会直接截取整个桌面。某些交互、音频响应或特殊项目不兼容，将回退到预览/基础主题；不包含、分发或上传用户壁纸资源。窗口隐藏或最小化时停止独立播放。透明度滑块只作用于壁纸模式卡片和侧栏，文字保持可读。

## 更新、卸载和数据

在“外观与通知”页下方的软件更新卡片或系统托盘菜单中点击“检查更新”。默认启动 8 秒后自动检查，程序持续运行时每 4 小时再检查一次。自动检查可关闭，手动检查仍可使用；完全退出程序后不检查。新版本需要已经在 GitHub 正式发布并上传完整的 Windows x64 安装包。

发现新版后点击“打开新版下载页”或托盘的“下载新版本”，下载安装包。软件不自动下载、安装或重启；检查失败会提示网络、频率限制等原因，原有签到计划不受影响。检查只请求公开版本元数据，不上传账号、日志或壁纸。

更新或卸载前先在托盘退出程序，等待正在执行的签到完成。安装程序检测到同一安装目录下仍有进程时会中止，避免覆盖运行中的程序。

更新保留账号数据并将已托管计划指向新的安装路径。若提示任务迁移失败，请打开程序逐个账号检查时间，重新启用计划；不要认为失败提示后任务已恢复。

卸载清理指向该目录的托管任务，并删除程序、快捷方式和卸载入口。个人配置保留在 `%LOCALAPPDATA%\AHUTSignIn`，重装后可继续使用；如不再需要，在卸载后自行删除此目录即可。DPAPI 凭据不能直接复制给另一个 Windows 用户解密。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 密码验证失败 | 确认使用考勤系统密码，检查网络与学校系统；更正后重试 |
| 计划没有执行 | 检查电脑开机、登录、网络、任务是否启用及北京时间；查看对应账号日志 |
| 没有结果通知 | 保持托盘运行，检查 Windows 通知设置；退出托盘后只保留计划运行 |
| 壁纸不动或显示预览 | 启动 Wallpaper Engine，换兼容项目或切换基础主题；考勤功能仍可用 |
| 账号显示凭据待修复 | 移除该账号后在线重新添加，另一账号仍可管理 |
| 时间输入不可用 | 先验证账号；点击时间数字输入或使用上下箭头，保存后确认计划状态 |

本版本只支持普通版本机模式，VPS 功能尚未开放。

## 1.5.0 改进

分钟调整支持跨小时进退：22:00 减一分钟为 21:59。新保存时间限制为北京时间 21:30–23:30，到边界停止；旧配置若超出范围，保留配置并提示重新选择时间。

窗口外框与标题栏随主题变化，在支持的 Windows 11 上使用系统磨砂材质和柔和阴影；Windows 10 或关闭系统透明效果时自动降级。保留系统标题栏的拖动、缩放和贴靠行为。

主页以更大的勾选状态和倒计时显示计划；任务缺失、未启用、时间或执行路径不匹配、保存失败等原因直接显示。系统任务退出码为 0 并不等于学校已确认签到，未取得本地成功记录时会显示核实提示。

计划保存改为一次进程调用完成注册、回读校验和必要的系统任务回滚，只有校验通过并保存配置后才显示成功。旧版 DSH 任务可在来源标记与执行脚本一致时安全接管。
