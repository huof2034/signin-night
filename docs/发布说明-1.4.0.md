# 晚安助手 1.4.0 · Windows 普通版

Windows 10/11 x64 安装包，当前用户安装，包含桌面快捷方式与卸载入口，无需配置 Python/Node 环境。

- 最多两个账号，各自在线验证、独立定时、启用/暂停和签到记录。
- 密码框下显示“考勤系统默认密码为：Ahgydx@920”，不自动填充。
- 保留浅色、夜间、跟随系统、静音动态壁纸、透明度、开启动画、托盘与通知。
- 损坏凭据单独显示待修复，避免阻塞另一账号。
- 升级更新托管任务的执行路径；卸载仅清理指向该安装目录的任务，并保留个人数据。
- 发布源代码与安装包均排除开发者账号、凭据、SSH/VPS 配置、日志和个人壁纸。

下载附件 `AHUTSignIn-Setup-1.4.0-x64.exe`，安装后添加自己的账号、设置北京时间并启用计划。默认 22:00，新账号计划默认暂停。电脑需开机、用户已登录、联网；实际签到以学校接口为准。

[中文使用说明](https://github.com/huof2034/signin-night/blob/main/docs/使用说明.md) · [项目首页](https://github.com/huof2034/signin-night)

动态壁纸需要已安装 Wallpaper Engine 和兼容项目，独立播放不保证与桌面动画进度一致；不兼容时回退到预览或基础主题。VPS 功能本版不开放。安装包尚未购买代码签名证书，可通过附件 `SHA256SUMS.txt` 校验。

## 发布验证

在 Windows 11 x64 完成 104 项离线回归测试、16 项打包后 Qt 界面检查、12 项安装/启动/升级/卸载检查；验证了空账号首次启动、错误密码可重试、独立计划、运行中覆盖拦截、卸载保留数据、安装包依赖与源码隐私隔离。

Windows 10 尚未在独立实机上测试；离线测试没有提交真实学校签到，学校在线服务与特殊动态壁纸项目需以实际使用结果为准。
